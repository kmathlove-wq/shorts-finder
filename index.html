조회수: 길이: 오늘 남은 검색: 약 ?번
이름을 쓰면 추천템·애장품 영상을 찾아 조회수 순으로 보여줘요. 영상은 조사용으로만 보고, 물건 이름을 노트에 담으세요!
📸 내가 직접 찍은 사진·영상만 넣어요. 연예인 사진이나 남의 영상을 넣으면 저작권·초상권에 걸려요. 음악은 유튜브 오디오 보관함의 무료 음악을 내려받아 쓰면 안전해요.
🎞️ 사진·영상 (순서대로 이어져요)
사진이나 영상을 추가해 주세요
🎵 소리
만드는 동안 이 화면을 켜 두세요 (다른 창으로 가거나 화면이 꺼지면 멈춰요)
✍️ 복사해서 붙여넣기
제목은 100자까지예요. 고쳐 써도 돼요!
✅ 올리기 전 확인 (다 체크해야 버튼이 켜져요)
📱 올리는 순서
  1. 유튜브 스튜디오에서 만들기 → 동영상 업로드 (휴대폰은 유튜브 앱 ＋ 버튼)
  2. 🎬 탭에서 만든 영상 파일 고르기 → 세로 + 3분 이하라서 자동으로 쇼츠가 돼요
  3. 위에서 복사한 제목·설명 붙여넣기
  4. "자세히 보기"에서 유료 프로모션 체크 (판매 링크가 있을 때)
  5. 처음엔 비공개로 올려서 확인한 뒤 공개로 바꾸면 안전해요
